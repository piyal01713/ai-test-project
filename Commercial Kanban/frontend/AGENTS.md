# Frontend Documentation

## Overview
The `frontend/` directory contains the Next.js frontend application for the Commercial Kanban Project Management MVP.

## Expected Structure
- Next.js static export layout.
- Components for Kanban board, columns, cards, and drag-and-drop interactions.
- Styling following the defined color scheme:
  - Accent Yellow: `#ecad0a`
  - Blue Primary: `#209dd7`
  - Purple Secondary: `#753991`
  - Dark Navy: `#032147`
  - Gray Text: `#888888`
